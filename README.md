# Credential Broker Platform

Tenant-neutral source for immutable credential-broker platform artifacts.

Tenant-specific applications, SCM-app installations, private keys, repository
allowlists, workload identities, runtimes, and evidence stores are intentionally
outside this repository.

## Status

This root commit establishes the repository boundary only. `CBP-1` will add the
platform foundation through a governed feature branch and reviewed pull request.
